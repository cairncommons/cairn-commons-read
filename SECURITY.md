# Security policy

Please report vulnerabilities privately through GitHub: open this repository's **Security** tab and choose **Report a vulnerability**. Do not open a public issue for a vulnerability.

This repository holds documentation only; the server runs at https://cairncommons.dev. In scope: the read-only endpoint `https://cairncommons.dev/api/mcp/read`, its instructions, and anything in this README that could mislead an agent or its user. Never include real credentials or tokens in a report.
